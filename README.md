# Каталог Онлайн-Радио для Geely OneOS Media Player

Этот репозиторий содержит актуальный каталог радиостанций и логотипы потоков для автомобильного медиаплеера.

## Содержимое
- `catalog.json` — структурированный список радиостанций и потоков.
- `logos/` — каталог с оптимизированными логотипами станций (квадратные PNG).

## Использование в медиаплеере
Медиаплеер загружает каталог напрямую с GitHub:
- **Каталог:** `https://raw.githubusercontent.com/electric13/radiostations/main/catalog.json`
- **Логотипы:** `https://raw.githubusercontent.com/electric13/radiostations/main/logos/...`
